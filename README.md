# Vishal Kumawat | Personal Portfolio

A modern, responsive personal portfolio website for **Vishal Kumawat**, a BCA student at Maharani College, Jaipur. Built with plain HTML, CSS and JavaScript in a single file, with a dark, minimal design.

**Live site:** https://xarvis29-source.github.io

## Features

- Dark theme with glass-style cards, white borders and subtle glow effects
- Fully responsive for mobile, tablet and desktop
- Sections: Hero, About, Skills, Projects, Education, Contact
- Animated skill progress bars that fill as you scroll
- Contact form that opens the visitor's email app (no backend needed)
- Semantic HTML5, keyboard-friendly focus styles and reduced-motion support
- No frameworks, no external files, no build step

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, custom properties, animations)
- Vanilla JavaScript

## Run Locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/xarvis29-source/xarvis29-source.github.io.git
   ```
2. Open `index.html` in any web browser.

## Deploy with GitHub Pages

1. Create a repository named `xarvis29-source.github.io`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings > Pages**, choose the `main` branch and the `/ (root)` folder, then save.
4. Your site will be available at `https://xarvis29-source.github.io` after a minute or two.

## Customize

Everything is in `index.html` with comments marking each section:

- **Colors and fonts:** edit the CSS variables under `/* THEME */`
- **Skills:** change the `--level` value on each skill card
- **Projects:** edit or duplicate a `project` card and update the GitHub link
- **Contact details:** update the email and GitHub links in the Contact and Footer sections
